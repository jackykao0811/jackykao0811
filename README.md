### Selected work

**[`luoshu-druggability`](https://github.com/jackykao0811/luoshu-druggability)** — Geometric pharmacology
Predicting kinase-inhibitor behaviour from ligand geometry: catechol-bidentate coordination, planarity, and gatekeeper accessibility. In a blinded MAP4K2 assay the framework achieved 5/5 binary accuracy with the correct potency ranking. Predictions for other kinases, including c-Abl, remain **hypotheses pending recombinant kinase assay** and are not presented as validated results.
Includes an audit script and confidence-interval analysis for reproduction. Preprint: [10.5281/zenodo.20085516](https://doi.org/10.5281/zenodo.20085516)

**[`hetu`](https://github.com/jackykao0811/hetu)** — Symmetry-constrained projection library
An installable Python package implementing He-Tu symmetry-constrained projection operators, with a test suite, worked examples, and a citable release. Archived at [10.5281/zenodo.19784150](https://doi.org/10.5281/zenodo.19784150)

### How I label claims

I keep validated results and open hypotheses strictly separate. Where something has been tested, I state the test and its scope; where it has not, I label it a hypothesis and say what experiment would settle it. Spectral measures such as the Fiedler value are reported only as descriptions of network cohesion and integration — never as evidence of causality, competitiveness, or clinical efficacy.

Issues and corrections are genuinely welcome.
